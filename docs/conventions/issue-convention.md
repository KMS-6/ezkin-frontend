# Issue 컨벤션

## 1. 목적

Issue를 기능 구현, 버그 수정, 문서화, 논의, 결정 사항으로 구분하여 팀의 진행 상태와 우선순위를 쉽게 파악하도록 한다.

## 2. 제목 형식

```text
[타입] 작업 내용
```

예:

```text
[Feature] 학생 Agent 기본 프로필 구조 정의
[Bug] 이벤트 발생 조건이 중복 적용되는 문제 수정
[Docs] AI Context 문서 템플릿 작성
[Decision] MVP 범위 확정
[Discussion] 사용자 개입 방식 논의
[Refactor] Agent 상태 업데이트 로직 분리
[Chore] 프로젝트 초기 환경 설정
```

## 3. 라벨

| 라벨 | 의미 |
|---|---|
| `feature` | 새로운 기능 |
| `bug` | 오류 수정 |
| `docs` | 문서 작성과 수정 |
| `design` | 화면, UX, 구조 설계 |
| `refactor` | 기능 변경 없는 코드 개선 |
| `chore` | 환경 설정과 패키지 관리 |
| `discussion` | 논의가 피요한 사항 |
| `decision` | 결정된 사항 기록 |
| `ai-context` | AI 사용 컨텍스트 문서 |
| `blocked` | 다른 작업에 막힌 상태 |
| `question` | 화인이 피요한 질문 |

## 4. 작성 양식

```markdown
## 작업 목적

이 Issue에서 해결하려는 문제나 구현하려는 기능을 작성한다.

## 작업 내용

- [ ] 작업 1
- [ ] 작업 2
- [ ] 작업 3

## 완료 기준

- 어떤 상태가 되면 완료로 볼 수 있는지 작성한다.

## 참고 자료

- 관련 문서
- 관련 회의록
- 관련 Decision Log
- 관련 PR

## 추가 메모

논의가 피요한 부분이나 주의할 점을 작성한다.
```
