# 버전 관리 컨벤션

## 1. 버전 형식

버전은 Semantic Versioning의 `MAJOR.MINOR.PATCH` 형식을 사용한다.

| 위치 | 올림 기준 | 예시 |
|---|---|---|
| `MAJOR` | 하위 호환을 깨뜨리는 파괴적 변경 | API 계약 전면 변경, 데이터 마이그레이션 |
| `MINOR` | 하위 호환을 유지한 새 기능 | 새 화면, API 엔드포인트, 편의 기능 |
| `PATCH` | 오류 수정과 사소한 내부 개선 | 버그 수정, 오탈자, 성능 개선 |

## 2. 개발 단계

### 0.y.z

초기 개발과 프로토타입 단계다. 하위 호환을 유지한 기능 단위로 `MINOR`를 올린다.

### 1.0.0

핵심 기능이 완성되어 평가자와 사용자에게 공식 제출할 때 사용한다.

### 1.x.x 이후

운영과 유지보수 단계로 간주하며 하위 호환성을 어기는 변경은 `MAJOR`로 관리한다.

## 3. Changelog

- 저장소 루트의 `CHANGELOG.md`에 실제 버전별 주요 변경을 기록한다.
- 릴리스 전에는 제출 내용으로 변경을 구분한다.
- 항목은 `Added`, `Changed`, `Fixed`, `Removed`, `Security`를 기본으로 사용한다.
- 컴밋 목록이 아니라 사용자에게 의미 있는 변경을 문장으로 작성한다.
